接入

网页、uTools 插件、MCP 和 HTTP 接口共用同一个访问令牌，即服务端 .env 中的 WENJI_TOKEN。令牌等同于全部权限，请勿外传。

MCP 接口

让 Claude Code、Claude Desktop、Cursor 等支持 MCP 的工具直接查询录音、转写、纪要和脑图。所有工具都是只读的。

工具

工具参数作用
list_recordingsquery since limit按关键词或日期（YYYY-MM-DD 起）列出录音，按录音时间倒序
search_transcriptsquery limit全文搜索转写，返回命中的句子、所在录音、时间点（毫秒）和说话人
get_recordingrecording_id录音元信息：标题、时间、时长、处理状态、说话人命名、所用模型
get_transcriptrecording_id完整转写稿，每行「[HH:MM:SS] 说话人：内容」，已应用说话人命名
get_summaryrecording_id纪要（Markdown）：总结、章节概要、金句、待办
get_mindmaprecording_id脑图大纲（Markdown），可直接交给 markmap 渲染

典型用法：先用 list_recordings 或 search_transcripts 找到录音 id，再读取转写或纪要。状态不是“已完成”的录音可能还没有转写或纪要。

uTools 插件

          
在 MacBook 上插入录音卡后自动同步到这里。插件“设置”中填写：

          
    
            
  • 服务地址：。可以保存多个地址（例如家里内网地址和穿透后的 HTTPS 地址），当前地址连不上时自动切换。
    • 
            
  • 访问令牌：同上面的令牌。
    • 
          

          
插件每 3 秒检查一次 /Volumes，含 record/ 目录的卷视为录音卡；先按“文件名 + 大小”比对，服务端已有的直接跳过，缺失的按 8MB 分片续传。

        


        

          
HTTP 接口

          
插件和网页使用的接口，需要请求头 Authorization: Bearer <令牌>。

          

            
接口作用

            
              
POST /api/sync/check按 {"items":[{"name","size"}]} 比对，返回 synced / partial（含 offset）/ missing

              
POST /api/uploads创建或恢复上传会话 {"name","size","source"}，返回 upload_id 和已上传偏移

              
PUT /api/uploads/{id}上传分片，请求头 Upload-Offset，单片不超过 16MB；传完自动入库并开始转写

              
GET /api/recordings?q=录音列表，q 搜索标题、转写和纪要

              
GET /api/recordings/{id}录音详情，含转写分段、纪要、脑图

              
GET /api/recordings/{id}/audio播放用音频（m4a）

              
POST /api/recordings/{id}/process重新处理，{"kind":"full"} 转写 + 纪要，{"kind":"summary"} 只重新生成纪要

              
GET /healthz健康检查，无需令牌
